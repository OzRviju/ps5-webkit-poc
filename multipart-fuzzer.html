Multipart x-mixed-replace Fuzzer

Target: CurlMultipartHandle::findBoundary() / parseHeadersIfPossible()
Modified by Sony (Feb 2025). Parses attacker-controlled boundary strings.
Uses a local python server to serve malformed multipart responses.

Iterations: 0

HOW TO USE:
1. Start the Python server on your PC (or PS5 if possible):
python multipart-server.py
2. Open this page on PS5 pointing to your server
3. Or use the inline fetch-based fuzzer below (limited by CORS)

The Python server generates malformed multipart responses with:
- Boundary strings with special chars / extreme length
- Truncated parts mid-header
- Missing CRLF terminators
- Close delimiter without final CRLF
- Overlapping boundaries
- Headers exceeding 300KB limit
